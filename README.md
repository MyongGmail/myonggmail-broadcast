# 명지메일 방송 모듈 (공개 서킷)

명지대 공지·비교과 정보를 수집해 **정적 방송 파일**로 송출하는 파이프라인 — 명지메일 소프트웨어
패밀리의 4서킷 중 **3번 방송 서킷**의 공개 구현체다.

## 왜 이 모듈만 공개인가

이 모듈은 **입력도 출력도 전부 공개 데이터**다: 입력은 학교의 공개 게시판(robots.txt 준수·요청 간
1.2초의 예절 크롤), 출력은 누구나 받는 정적 방송 파일. 설계 원칙("방송은 털려도 지장이 없다 —
복호화할 대상을 소거한다")에 따라 코드 공개가 무해하며, 오히려 크롤 예절과 데이터 취급의 투명성을
증명한다. 본체(앱·콘솔·관리)는 비공개이며 이 모듈과 **공유 비밀이 없다**(해킹 격리 원칙).

## 구성

- `pipeline/crawler/v2/` — 채널 설정 구동 크롤러(신규 채널 = mju.json 행 추가, 코드 수정 없음)
- `pipeline/broadcast/` — 방송 생성기 v0: 라인 포맷(`채널|글번호|날짜|태그|제목`), 코드→의미
  사전은 전송로 밖(수신기 내장). `python3 -m pipeline.broadcast.generate --verify`
- `.github/workflows/crawl.yml` — 일 5회 크론: 크롤 → 방송 재생성·검증 → R2 정적 서빙 동기화

## 보안 노트(감사 요약)

- 워크플로 트리거는 `schedule`·`workflow_dispatch`뿐 — PR 계열 트리거 없음(인젝션 표면 0)
- **완전 격리(C3)**: 이 모듈의 접합부는 두 개뿐 — 공개 게시판(입력)과 R2 버킷(출력).
  본체 백엔드(DB·인증·관리)와는 어떤 자격증명도 공유하지 않는다 — 유일한 비밀은 버킷 2종
  한정 R2 토큰이며, 최악의 유출 시에도 영향 반경은 방송·스냅샷 버킷을 넘지 못한다
- R2 자격증명은 방송·스냅샷 버킷 2종에만 한정된 최소 권한 토큰
